# Insta4DL — Android WebView App (v1.0.0)

**Official target site:** https://www.insta4dl.com/

یک اپ اندرویدی اختصاصی WebView برای سایت Insta4DL؛ **کاملاً رایگان و بدون ثبت‌نام یا ورود به حساب کاربری**. سورس پروژه آماده ساخت فایل APK است.

## امکانات

- نمایش نسخه موبایل و ریسپانسیو وب‌سایت، فعال بودن JavaScript و local storage.
- دریافت لینک از `Instagram → Share → Insta4DL` و قرار دادن آن داخل کادر سایت؛ سپس دکمه Download سایت را بزنید.
- دکمه Paste برای انتقال لینک معتبر Instagram از کلیپ‌بورد به سایت.
- پشتیبانی از دانلود لینک مستقیم HTTPS با Android DownloadManager.
- پشتیبانی از دانلود `blob:` (در صورت پشتیبانی Android System WebView) با ارتباط WebMessage امن، محدودشده به دامنه Insta4DL و ارسال فایل به Downloads بدون دسترسی گسترده به فایل‌ها.
- ذخیره دانلودها در `Downloads/Insta4DL` و دکمه Files برای باز کردن بخش دانلودها.
- تب‌های سایت و دکمه‌های Home و Reload؛ باز شدن سایت‌های متفرقه در مرورگر سیستم.
- بدون تبلیغات اضافه در اپ، بدون حساب کاربری، بدون SDK تحلیل رفتار و فقط مجوز اینترنت.

> این یک WebView است: امکانات دانلود به درست کار کردن سایت و APIهای موجود آن وابسته‌اند. APK قابلیت عبور از محدودیت‌های Instagram یا فعال کردن لینک‌های غیرقابل‌دسترس را اضافه نمی‌کند.

## ساده‌ترین روش: ساخت رایگان APK با GitHub Actions

1. فایل ZIP پروژه را روی کامپیوتر **Extract** کنید.
2. در https://github.com یک حساب رایگان داشته باشید یا بسازید و یک مخزن جدید با نام `Insta4DL-Android` بسازید. برای استفاده رایگان معمولی، می‌توانید مخزن را **Public** قرار دهید (در فایل‌های پروژه هیچ کلید شخصی وجود ندارد).
3. گزینه **Add file → Upload files** را بزنید. **تمام محتویات** پوشه پروژه را به همان ساختار آپلود کنید؛ حتماً پوشه مخفی `.github/workflows/build-apk.yml` هم منتقل شود (کل پوشه پروژه را به‌عنوان یک فایل ZIP آپلود نکنید).
4. روی **Commit changes** بزنید.
5. وارد تب **Actions** شوید، workflow به نام **Build Insta4DL APK** را انتخاب کنید. معمولاً با Commit خودکار اجرا می‌شود. در غیر این صورت گزینه **Run workflow** را بزنید.
6. پس از سبز شدن نتیجه، روی آخرین اجرای workflow کلیک کنید و در بخش **Artifacts**، فایل **Insta4DL-v1.0.0-debug-APK** را دانلود کنید.
7. آرشیو دریافتی را Extract کنید. داخل آن فایل `app-debug.apk` قرار دارد. آن را روی گوشی اندرویدی منتقل و نصب کنید. ممکن است لازم باشد اجازه «Install unknown apps» را به اپ Files بدهید.

**هزینه ساخت:** برای استفاده در محدوده سهمیه رایگان GitHub Actions نیاز به پرداخت ندارید. برای ساخت با GitHub فقط سازنده به حساب GitHub احتیاج دارد؛ کاربران اپ هیچ حسابی لازم ندارند.

## روش جایگزین: Android Studio روی کامپیوتر

1. Android Studio رایگان را نصب کنید و پوشه پروژه را باز کنید.
2. صبر کنید Gradle پروژه را همگام کند و Android SDK API 35 دانلود شود.
3. منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)** را بزنید.
4. فایل خروجی این مسیر است: `app/build/outputs/apk/debug/app-debug.apk`.

## مشخصات فنی

- Java 17، Gradle 8.10.2، Android Gradle Plugin 8.7.3.
- AndroidX WebKit 1.14.0؛ `minSdk=29` (اندروید 10 به بالا)، `targetSdk=35`.
- شناسه اپ: `com.insta4dl.app`؛ نسخه `1.0.0`.
- فقط دسترسی `INTERNET` درخواست می‌شود. ذخیره فایل‌ها با MediaStore یا DownloadManager صورت می‌گیرد.
- فایل‌های وب‌سایت روی سرور اصلی می‌مانند و اپ کپی محلی آن نیست.

## نکات نسخه آزمایشی

- GitHub خروجی **debug APK قابل نصب** تولید می‌کند. برای انتشار رسمی در Google Play باید نسخه Release با کلید امضای شخصی و دستورالعمل انتشار آماده شود.
- هر بار GitHub APK دیباگ را با کلید محلی مربوط به همان ماشین build امضا می‌کند؛ ممکن است برای نصب نسخه آزمایشی جدید نیاز باشد اپ قبلی را حذف کنید. برای به‌روزرسانی‌های بدون حذف، باید امضای ثابت شخصی تنظیم شود.
- فایل‌های ZIP / ویدیوهای بزرگ `blob:` بسته به حجم و توان گوشی باید روی دستگاه واقعی تست شوند. برای انتقال‌های حجیم، روش مستقیم HTTPS بهینه‌تر است.
- خروجی در محیط این گفتگو **کامپایل یا روی دستگاه نصب نشده**؛ کار GitHub Actions ساخت فایل APK است.
- سایت Insta4DL برای محتوای عمومی طراحی شده است. حقوق تولیدکنندگان محتوا را رعایت کنید.

## ساختار فایل‌های کلیدی

- `app/src/main/java/com/insta4dl/app/MainActivity.java`: پوسته اپ، اشتراک لینک و مدیریت دانلود.
- `app/src/main/assets/blob-bridge.js`: انتقال فایل‌های Blob از WebView به دانلودهای اندروید.
- `app/src/main/AndroidManifest.xml`: تنظیمات اندروید و Share Target.
- `.github/workflows/build-apk.yml`: ساخت خودکار APK در GitHub.
- `ICON-512.png`: آیکون اپ.
